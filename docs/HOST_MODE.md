# 局域网主机模式指南

主机模式让一台持续运行 LeetTutor 的电脑负责题解运行、学习进度、模型服务和 API Key，手机、平板或另一台电脑只负责显示浏览器界面。主机可以是任意能够运行本项目的 macOS、Windows 或 Linux 设备。

## 1. 首次准备

1. 在准备作为主机的电脑上下载并打开本仓库。
2. 先使用普通启动入口，等待依赖安装完成。
3. 如果要用本地模型，在侧栏完成 Ollama、LM Studio 或可用硬件后端的设置。
4. 如果要用 OpenAI API 或 Gemini API，只在主机本地页面粘贴 API Key 并点击“保存设置”。
5. 关闭普通启动窗口，再启动主机模式：macOS 双击 `run-lan.command`，Windows 双击 `run-lan.bat`，Linux 或终端运行 `python3 scripts/launch.py --lan`。

主机模式会监听 `0.0.0.0:8501`，启动器只展示当前局域网地址。每次启动都会生成新的 8 位访问码；二维码只包含访问地址，不包含访问码。

## 2. 手机连接与免重复验证

启动窗口会显示类似内容：

```text
[LeetTutor] 手机访问地址：http://192.168.1.25:8501
[LeetTutor] 本次访问码：12345678
```

让手机与主机连接同一个可信 Wi-Fi，然后：

1. 在手机浏览器打开该地址，或扫描主机页面侧栏里的二维码；
2. 输入启动窗口中的本次访问码；
3. 保持默认勾选的“在此浏览器记住这台主机 30 天”；
4. 正常选择题目、写代码和使用 JARVIS。

验证成功后，浏览器只保存由该主机签名的随机凭证，不保存 8 位访问码。之后刷新页面、关闭再打开浏览器或重启主机，都可以自动进入。以下情况需要重新验证：

- 换了浏览器、手机或无痕窗口；
- 清除了该地址的网站数据；
- 主机的 IP 地址或端口变化，浏览器把它视为新的站点；
- 可信凭证超过 30 天；
- 主机删除 `.leettutor/lan-trust-secret`，撤销了所有已配对浏览器。

在公共或共享设备上应取消“记住这台主机”。主机的信任密钥仅保存在 Git 忽略的 `.leettutor/lan-trust-secret`，文件权限会尽量设为 `0600`。

## 3. 手机界面怎么用

当前移动布局以 iPhone 13 Pro 的 390 × 844 CSS 像素和 iPhone Air 的 420 × 912 CSS 像素为验收尺寸，同时兼容不超过 760 像素宽的手机浏览器：

- 算法模式底部固定“题目 / 代码 / JARVIS”，默认显示代码；
- 系统设计底部固定“任务 / 现场 / JARVIS”；
- 题目与代码每次只显示一个完整面板，避免两栏缩窄或无限向下堆叠；
- JARVIS 在手机上打开为全宽对话面板，并跟随可视窗口高度避开软键盘和底部安全区；
- 系统设计的继续回答栏固定在底部导航上方；
- 模型设置侧栏首次会自动收起，点击左上角 `LT` 可以重新打开。

建议使用 Safari 或 Chrome 的当前版本。横屏同样可用，但写代码和阅读题面仍推荐竖屏；系统字体放大到很高比例时，按钮文字可能换成两行，这是为了保留完整含义和可触控区域。

学习进度、保存到仓库的题解以及模型/API 配置都位于主机。未保存的编辑器草稿和聊天记录属于浏览器会话，不会在手机与电脑之间实时合并。

## 4. 防火墙与路由器设置

- 系统防火墙首次询问 Python 是否接受传入连接时，选择“允许”。
- 主机必须保持开机和联网，并避免进入会停止网络服务的深度睡眠。
- 某些访客网络启用了“客户端隔离”，同一 Wi-Fi 的设备仍无法互相访问；请改用主网络。
- 地址可能在重连或重启路由器后改变，以启动窗口本次显示的地址为准。
- 不需要、也不应该配置端口转发、DMZ、动态 DNS 或公网反向代理。

## 5. API Key 安全边界

云端密钥有两种推荐配置方式。

### App 内本地配置

先在主机上使用普通模式打开 App，选择 OpenAI API 或 Gemini API，粘贴密钥并保存。密钥写入：

```text
.leettutor/secrets.json
```

该目录已被 Git 忽略，密钥文件权限为 `0600`。后续使用主机模式时，远程浏览器只能看到是否已配置，不能查看或修改密钥。

### `.env` 配置

复制 `.env.example` 为 `.env`，选择性填写：

```bash
LEETTUTOR_OPENAI_API_KEY=...
LEETTUTOR_GEMINI_API_KEY=...
```

也支持标准环境变量 `OPENAI_API_KEY` 和 `GEMINI_API_KEY`。不要提交 `.env`、`.leettutor/secrets.json` 或 `.leettutor/lan-trust-secret`。

ChatGPT Plus/Pro 与 OpenAI Platform API 是独立产品；Gemini 网页会员与 Gemini API 也分开。App 不能把网页会员登录转换成 API 调用权限，仍需要各平台的 API Key 和可用 API 额度。

## 6. 安全说明

局域网入口要求首次访问码验证，已配对浏览器使用 30 天有效的主机签名凭证。但它仍是普通 HTTP：

- 只在信任的家庭或私人办公 Wi-Fi 中使用；
- 不在酒店、机场、咖啡店或其他公共网络启用；
- 不把 `8501` 端口映射到公网；
- 局域网页面不允许编辑 API Key，避免密钥经 HTTP 发送；
- 删除 `.leettutor/lan-trust-secret` 并重启主机模式，可以撤销所有浏览器的长期信任；
- 停止启动窗口中的进程会立即关闭网络入口，但已签发的浏览器凭证会在下次启动后继续有效，直到到期或被撤销。

如果未来需要从互联网远程访问，应使用带 HTTPS、身份认证和访问策略的 VPN 或零信任隧道；这不属于当前“同一 Wi-Fi”主机模式。

## 7. 常见问题

### 手机打不开地址

1. 确认两台设备在同一个非访客 Wi-Fi；
2. 保持主机的启动窗口正在运行；
3. 检查系统防火墙是否允许 Python；
4. 重新运行 `run-lan.command`，使用新显示的地址；
5. 检查路由器是否启用了 AP/客户端隔离。

### 为什么又要求输入访问码

最常见原因是主机 IP 或端口变化、浏览器处于无痕模式、网站数据被清除，或者 30 天信任期已经到期。确认地址没有变化，并在私人设备上保持“记住这台主机”开启。

### 如何撤销所有已信任设备

停止 LeetTutor，删除主机上的 `.leettutor/lan-trust-secret`，再重新启动主机模式。启动器会生成新的签名密钥，之前所有浏览器凭证都会失效；当前访问码仍只显示在新的启动窗口中。

### 页面能打开，但云端模型提示没有 API Key

局域网模式故意禁止编辑密钥。停止服务，在主机本地使用普通模式配置并保存，再重新运行主机模式。

### 电脑上的未保存代码没有出现在手机

学习进度和已保存题解是服务器端持久数据；活动编辑器和聊天是浏览器会话数据。换设备前请在“保存到仓库”中保存题解。
